# BatumiLeads

Учебный проект курса RS School (JS FullStack): витрина проверенных контактов собственников недвижимости Батуми для риелторов. Риелтор находит объекты в каталоге, фильтрует их по району и цене, складывает нужные контакты в корзину и применяет промокод.

> Демо-версия: оплата не подключена, данные тестовые.

## Ссылки

- Деплой на Vercel: https://rs-fullstack-team-projec-git-20af5f-vladimirs-projects-0aed3f32.vercel.app/
- Доска задач: https://github.com/users/Val-d-emar/projects/7

## Экраны

- **О нас** — описание сервиса, статистика каталога, команда.
- **Каталог** — поиск по названию, району и ID, фильтры по району и цене, сортировка, модальное окно с галереей и деталями объекта.
- **Корзина** — выбранные объекты, промокоды, итоговая сумма. Каждый контакт можно добавить только один раз.

## Стек

- TypeScript и Vite, без UI-фреймворков
- SCSS для стилей
- Vitest для тестов
- ESLint и Prettier для качества кода
- Husky и lint-staged для проверок перед коммитом

## Требования

Node.js 20.19+ (рекомендуется актуальная LTS-версия) и npm.

## Запуск

```bash
npm ci
npm run dev
```

`npm ci` ставит зависимости строго по `package-lock.json`. `npm run dev` запускает dev-сервер Vite, адрес появится в терминале.

## Проверки перед коммитом

Husky запускает lint-staged на изменённых файлах: для `*.ts` выполняются ESLint и Prettier, для `*.scss`, `*.css`, `*.json`, `*.md`, `*.yml` и `*.html` — Prettier.

## Скрипты

| Команда                | Что делает                                                  |
| ---------------------- | ----------------------------------------------------------- |
| `npm run dev`          | Dev-сервер Vite с горячей перезагрузкой                     |
| `npm run build`        | Проверка типов и production-сборка в `dist/`                |
| `npm run preview`      | Локальный просмотр собранного проекта                       |
| `npm test`             | Разовый прогон тестов Vitest                                |
| `npm run typecheck`    | Проверка типов TypeScript без сборки                        |
| `npm run lint`         | ESLint, предупреждения считаются ошибками                   |
| `npm run lint:fix`     | ESLint с автоисправлением                                   |
| `npm run format`       | Форматирование проекта Prettier                             |
| `npm run format:check` | Проверка форматирования без изменений                       |
| `npm run check`        | Типы, линтер, форматирование, тесты и сборка одной командой |

## Структура проекта

```
src/
├── data/      данные каталога и промокоды
├── domain/    бизнес-логика: фильтры и расчёт корзины
├── state/     хранилище состояния и работа с localStorage
├── styles/    SCSS-модули
├── types/     общие типы
├── ui/        компоненты и страницы
└── main.ts    точка входа, обработчики событий
```

Бизнес-логика в `domain/` и состояние в `state/` покрыты тестами и не зависят от DOM.
